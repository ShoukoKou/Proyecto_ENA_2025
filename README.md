# ✦ Proyecto ENA 2025

Proyecto final grupal del curso **Programación para Ciencia de Datos**.

El proyecto utiliza los microdatos de la **Encuesta Nacional Agropecuaria (ENA) 2025** para preparar, procesar y analizar información de las Unidades Agropecuarias (UA) del Perú, mediante tablas estadísticas, gráficos y mapas.

## Tecnologías utilizadas

- **Lenguaje:** Python
- **Entorno:** Jupyter Notebook
- **Bibliotecas:** Pandas y herramientas de análisis geoespacial
- **Formato de datos:** Excel (.xlsx) y Apache Parquet (.parquet)

## Estructura del proyecto

```text
Proyecto_ENA_2025/
│
```
