# ✦ Proyecto ENA 2025

Proyecto final grupal del curso **Programación para Ciencia de Datos**.

El proyecto utiliza los microdatos de la **Encuesta Nacional Agropecuaria (ENA) 2025** para preparar, procesar y posteriormente analizar información de las Unidades Agropecuarias (UA) del Perú.

## Estructura del proyecto

```text
Proyecto_ENA_2025/
│
├── data/
│   ├── raw/                 # Datos originales
│   └── procesado/           # Datos convertidos/procesados en .parquet
│
├── scripts/
│   ├── 01_conversion_parquet.ipynb
│   └── 02_analisis.ipynb
│
├── src/
│   └── funciones.py         # Funciones reutilizables
│
├── README.md
└── .gitignore
```
